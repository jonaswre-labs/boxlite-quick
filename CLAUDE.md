## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues for jonaswre/boxlite-quick, using the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Uses the default label names: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### Testing

Run the real-Box tests with `scripts/real-box`, never in the background. See `docs/agents/testing.md`.
